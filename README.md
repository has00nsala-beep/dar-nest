# Dar Nest – نظام الفواتير (نسخة Firebase)

نفس البرنامج، لكن البيانات والدخول على Firebase بتاعك. تقدر تفتحه من أي جهاز ومن أي مكان بدون حساب Claude.

## الملفات
- `index.html` – البرنامج كله
- `firebase-config.js` – **هنا تلصق إعدادات مشروعك** (الخطوة 3)
- `firestore.rules` – قواعد الحماية (الخطوة 2)
- `firebase.json` – إعدادات النشر على Firebase Hosting

## الخطوات (مرة واحدة)

### 1) فعّل تسجيل الدخول
Firebase Console ← مشروعك ← **Build ← Authentication ← Get started ← Sign-in method ← Email/Password ← Enable ← Save**.
(البرنامج بيستخدم اسم المستخدم، وبيحوّله داخليًا لإيميل وهمي، فمش هتشوف إيميلات.)

### 2) أنشئ قاعدة البيانات والقواعد
- **Build ← Firestore Database ← Create database** ← اختار أقرب منطقة ← **Production mode**.
- افتح تبويب **Rules**، امسح كل اللي فيه، والصق محتوى ملف `firestore.rules` كله، ثم **Publish**.

### 3) انسخ إعدادات الموقع
**Project settings (الترس) ← Your apps ← أيقونة الويب `</>` ← سمّي التطبيق ← Register app**، وانسخ القيم اللي في `firebaseConfig` والصقها في `firebase-config.js` بدل الكلام الإنجليزي.

### 4) انشر الموقع (اختار طريقة)

**أ) Firebase Hosting (على جهاز كمبيوتر):**
```
npm install -g firebase-tools
firebase login
firebase use YOUR_PROJECT_ID
firebase deploy
```
(نفّذها من داخل الفولدر ده). هيطلعلك رابط `https://YOUR_PROJECT_ID.web.app`.

**ب) الأسهل: Netlify Drop:** افتح netlify.com/drop واسحب الفولدر عليه، وهيعطيك رابط. بعدها ارجع لـ Firebase: **Authentication ← Settings ← Authorized domains ← Add domain** وضيف دومين الرابط.

### 5) أول تشغيل
افتح الرابط ← اضغط **"أول تشغيل؟ إنشاء حساب المالك"** ← اكتب اسمك واسم مستخدم وكلمة سر. ده يعمل مرة واحدة بس، بعدها يتقفل تلقائيًا.

بعد كده من صفحة **الموظفين** ضيف المدير والموظفين وموظفي المصنع، كل واحد باسم مستخدم وكلمة سر، وكل واحد يدخل من جهازه.

## ملاحظات مهمة
- **كلمة سر موظف نسيها:** المالك مش بيقدر يغيّرها من البرنامج. الحل: يعطّل الحساب القديم ويعمل حساب جديد باسم مستخدم تاني. وأي مستخدم يقدر يغيّر كلمة سره بنفسه من زر "كلمة السر" فوق.
- **الصور:** بتتصغّر تلقائيًا وتتحفظ جوه Firestore (مش محتاج Firebase Storage ولا خطة مدفوعة). صور فقط، مفيش PDF.
- **حذف الموظفين:** غير متاح (التعطيل بس)، عشان فواتيرهم تفضل مرتبطة بيهم.
- **الحماية:** قواعد `firestore.rules` بتتحقق من الدور على السيرفر نفسه: موظف المبيعات يقرأ فواتيره بس، وموظف المصنع يقرأ طلباته بس، والمالك وحده يدير الموظفين والإعدادات، ولا أحد يحذف فاتورة.
- **البيانات القديمة:** اللي كان في النسخة على Claude مش بتنتقل (كانت بيانات تجريبية).
- **التكلفة:** خطة Spark المجانية تكفي لمحل بحجم عادي.
